# 技术文档管理与结构化解析系统
软件工程基础实训课程项目

## 📖 项目简介
本项目是基于Java开发的技术文档管理系统，支持多种格式文档上传、解析与管理，实现自动目录生成、文档结构检查等功能，解决技术文档手动整理效率低、易出错的问题。

## 🚀 核心功能
- ✅ 多格式文档上传：支持 `.doc/.docx/.pdf/.txt` 四种格式
- ✅ 章节结构提取：自动识别一级、二级标题层级
- ✅ 自动目录生成：按标题层级生成带缩进的规范目录
- ✅ 文档结构检查：检测标题跳级等不规范问题
- ✅ 文档关键词搜索：快速查找已上传文档

## 🛠️ 技术栈
- 开发语言：Java 8
- 界面：Java Swing
- 文档解析：Apache POI、PDFBox
- 数据库：MySQL 8.0
- 开发工具：IntelliJ IDEA

## 📋 使用说明
1.  运行 `DocManagerApp.java`，启动程序
2.  点击「上传文档」，选择本地文件
3.  点击「生成目录」查看结构化目录
4.  点击「检查结构」校验文档格式
5.  输入文件名关键词，点击「搜索」快速定位文档
